# 官方服务说明

`TokensZhuanfa/Dujiao-Shop` **目前没有付费官方服务**。本仓库纯开源,MIT License,自托管。

如果你需要:

- **代部署**(VPS + 域名 + SSL + 起服务)
- **技术咨询**(性能优化 / 二次开发 / 接特定支付通道)
- **运维托管**(7x24 监控 / 备份 / 升级)

**当前未提供**。后续若开通,会在本页 + 仓库 README 公布。
