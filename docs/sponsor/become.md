# 成为赞助商

`TokensZhuanfa/Dujiao-Shop` 目前**没有付费赞助计划**。

## 你能做的支持

如果你觉得这个项目对你有用,可以:

- ⭐ **GitHub Star**:[`TokensZhuanfa/Dujiao-Shop`](https://github.com/TokensZhuanfa/Dujiao-Shop) — 最简单也最直接
- 🐛 **报 bug / 提需求**:[Issues](https://github.com/TokensZhuanfa/Dujiao-Shop/issues),哪怕只是描述清楚一个边缘场景的崩溃也很有帮助
- 🔧 **贡献 PR**:见 [开源仓库与贡献](/intro/repos#贡献)。文档错别字、UI 边角 bug、新支付通道都欢迎
- 📣 **分享**:在博客 / Telegram 群 / 论坛提到本项目,带链接最好
- 💬 **告诉别人你在用**:被看见 = 项目活下去的能量

## 未来计划

后续若开通 GitHub Sponsors 或类似计划,会在本页公布。
