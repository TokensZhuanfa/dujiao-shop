# 社区共享项目

社区维护的、跟 dujiao-shop 生态相关的项目。**未官方背书**,用前请自行 review 安全性。

## 收录的类型

- 支付通道的额外实现(如非内置的某些聚合支付)
- 主题 / 模板 / 配色方案
- 浏览器扩展(后台增强、价格对比等)
- 第三方运维工具(监控 / 备份脚本 / 等)

## 提交你的项目

欢迎在 [TokensZhuanfa/Dujiao-Shop/issues](https://github.com/TokensZhuanfa/Dujiao-Shop/issues) 开 issue,贴:

- 项目名 + GitHub / Gitee 链接
- 一段话说明用途
- License 类型
- 是否还在维护
